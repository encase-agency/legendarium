Источник: предоставленный Markdown «Легендариум_что_подготовить_для_разработчиков_docx_3.md» и [Google Drive документ](https://docs.google.com/document/d/1LpdbkM86qMjn2aArSjSIgspEevqxf55W/edit), изменённый 27 октября. Документ прочитан через подключённый Drive. Доступы из вложений не переносились, вход в аккаунты и публикация не выполнялись.

## Изменения

1. **Тарифы.** Последнее уточнение документа заменяет старый GetCourse-сценарий: цены, скидки и суммы рассрочки убраны из обоих тарифов и повторной мини-карточки в Story. «Получить доступ» Легенды ведёт на https://t.me/m/4VlmAiy-NDUy; кнопка в модалке Базового — на https://t.me/m/DlFOK1NJYmRi. Встроенный GetCourse не открывается и не загружается. Прежний компонент сохранён как неиспользуемый исходник. Ссылка Telegram открывает чат; сообщение не отправляется автоматически.
2. **Правовые материалы.** Через Drive прочитаны все четыре переданных документа, ссылки подключены в футер; тексты не сочинялись и не изменялись. Оферта доступна и из существующего блока Legal. Отдельный cookies-документ не запрашивается. По новой оферте автопродление требует отдельного согласия — это отражено в карточках. В FAQ убрано противоречие об одном факультете: Базовый даёт 12 направлений без обратной связи, поддержка зависит от тарифа.
3. **Cookie-выбор.** Баннер теперь виден и без идентификаторов аналитики: «Только необходимые», «Принять», «Настройки». Необходимые включены всегда, аналитические/маркетинговые исходно выключены. Выбор хранится 12 календарных месяцев, проверяется при загрузке и по истечении срока. Из футера открываются категории. Отзыв останавливает аналитику, удаляет доступные cookie `_ym_*` и перезагружает страницу для выгрузки сторонних слушателей. HttpOnly и cookie другого домена недоступны JavaScript лендинга. Маркетинговые технологии не установлены; категория сохраняет выбор на будущее.
4. **Метрика.** Номер не предоставлен, поэтому счётчик не включён. Добавлены consent-guarded цели tariff_legend_click / tariff_basic_click для нажатий на тарифные ссылки. Отправка формы и успешная оплата не имитируются: в текущем сценарии сайт не принимает оплату и не получает подтверждение заказа. Настройки домена GetCourse находятся вне этого репозитория.
5. **Отзывы Kinescope.** Подключены однозначные отзывы: Алексей, «1500$ за 3 дня», Андрей, Денис (короткий). Модалка загружает hosted iframe по клику, есть ссылка на оригинал; поток обслуживает Kinescope. Данила остаётся локальным. Даниэль и Егор не подменены без подтверждённого соответствия.
6. **Наставники.** «Заработок на контенте» добавлен первым перед ИИ; «Реклама ВК» — перед Telegram, в раскрываемом списке. Содержание технически названных роликов определено по публичным постерам: VIZITKA — Ян/контент, 0928(1) — вебинар по ВК. Использованы подтверждённые краткие описания и динамические постеры. Точная копия новых Figma-модалок не заявляется: сессия Figma MCP отказала из-за отсутствия edit access.
7. **Анимации.** В Statement/Mission раньше отсутствовали hooks/CSS анимации. Добавлен fade-in крупного текста при фактическом попадании в экран, с reduced-motion fallback и очисткой. Это добавление отсутствующего поведения, а не доказанное устранение всей Safari-проблемы. Фото и подпись не менялись без воспроизведения ошибки. Мобильный луч не исправлен: область canvas начинается ниже CTA, расширение требует отдельной геометрической/визуальной сверки.

- Область мобильного Hero расширена вверх с y=358 до y=299 (нижняя граница CTA) при ширине 390 px. UV повтор по вертикали умножается на 653/594, поэтому координаты портрета ниже старой границы математически сохранены. Проверено тестом на ширинах 320/390/768/1100; desktop использует прежний cover. За границами исходной текстуры alpha обнуляется, чтобы не растягивать крайний ряд пикселей. Браузер показал один canvas y=299..952, портрет не сдвинулся. Физический iPhone и точная сверка исходного рисунка луча остаются приёмкой; сама исходная текстура имеет верхнюю границу, её содержимое не дорисовывалось.

На desktop в начале страницы фото FounderPath скрыто, подпись имеет clip inset(0 100% 0 0); преждевременное воспроизведение в этой проверке не произошло. Сложный исходный сценарий Safari с медленной прокруткой всей страницы всё ещё не воспроизведён.
- Независимое ревью выявило и затем подтвердило устранение двух дефектов: цель Метрики во время загрузки скрипта теперь ждёт init; очередь очищается при отзыве. Ошибка записи отказа теперь удаляет прежнее согласие, если это доступно; перезагрузка разрешена только после проверки, что старое согласие не восстановится. Если хранилище полностью заблокировано, аналитика выключается в текущей вкладке, перезагрузка не выполняется, пользователю показывается сообщение. Три регрессионных теста покрывают эти случаи.

- Итог: 45 тестов, build/typecheck проходят, lint 0 ошибок/3 прежних предупреждения. Ревью не нашло оставшихся блокеров в проверенном коде. Последние изменения пока локальные.
